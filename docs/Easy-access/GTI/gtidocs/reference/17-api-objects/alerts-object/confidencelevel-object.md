# confidencelevel

Enum to indicate the level of confidence in a verdict.

Here is the `Enums` table from the `ConfidenceLevel` resource formatted as a markdown list:

* **`CONFIDENCE_LEVEL_UNSPECIFIED`**: Default value. Confidence level is not specified.
* **`CONFIDENCE_LEVEL_LOW`**: Low confidence in the verdict.
* **`CONFIDENCE_LEVEL_MEDIUM`**: Medium confidence in the verdict.
* **`CONFIDENCE_LEVEL_HIGH`**: High confidence in the verdict.
