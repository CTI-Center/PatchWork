# dark-web-conversation-thread

A Dark Web Conversation Thread represents a chronological collection of related communications, typically organized around an initial post or a specific topic of discussion.

Its `type` is set to `ddw_conversation_thread` and is only applicable to [Dark Web Communications](dark-web-communication-object.md) with a `communication_type` of `forum_post` or `messenger_message`.
