# 🔀-collections

Collections containing this file.

The *collections* relationship lists all VirusTotal's collections where this file is contained.

This relationship can be retrieved using the [relationships API endpoint](../../03-ioc-investigation/files/files-relationships.md). The response contains a list of [Collections](../ioc-collection-object.md) objects.

```json /files/{file}/collections
{
  "data": [
    <COLLECTION_OBJECT>,
    <COLLECTION_OBJECT>,
    ...
  ],
  "links": {
    "next": "<string>",
    "self": "<string>"
  },
  "meta": {
    "count": <int>,
    "cursor": "<string>"
  }
}
```
