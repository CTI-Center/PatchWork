# openapi-specifications

Alongside the comprehensive Google Threat Intelligence API documentation on this portal, we also offer OpenAPI Specifications. These specifications provide a complete description of all API endpoints, allowing you to easily explore and test our API using your preferred tools.

You can download OpenAPI Specifications JSON files for:

* [ASM (Attack Surface Management)](https://gtidocs.virustotal.com/openapi/asm-attack-surface-management.json)
* [DTM (Digital Threat Monitoring)](https://gtidocs.virustotal.com/openapi/dtm-digital-threat-monitoring.json)
* and the rest of the Google TI tools from [here](https://storage.googleapis.com/gtidocresources/guides/GTI_API_v3_openapi_spec_10022025.json).
