# url-intelligence-feed

The URL feed is a continuous real-time stream of JSON-encoded structures that contains information about each URL analyzed by Google Threat Intelligence. Those JSON-encoded structures are put together in batches, with a new batch generated every minute. The batch consists of a text file containing one JSON structure per line.

> 🚧 Special privileges required
>
> URL feeds endpoints are only available to users with a URL feeds license. [Contact us](https://www.virustotal.com/gui/contact-us/) for more information.
