# zipping-files

You can download individual files from Google Threat Intelligence by using the [GET /files/\{id}/download](zipping-files/zip-files-download.md) and [GET /files/\{id}/download\_url](zipping-files/zip-files-download-url.md) endpoints, however, sometimes you may want to download files in bulk in a password-protected ZIP file. This is specially useful in corporate environments where a gateway antivirus may be blocking your downloads because they contain malware (as expected from files downloaded from Google TI)
