# collection-scan-rate

In Attack Surface Management (ASM), scan rate is the frequency with which Collection scans are initiated. ASM scan rate options are:

* **On Demand**: Scans must be manually initiated.
* **Daily**
* **Weekly**
* **Monthly**

## manually-initiate-a-collection-scan

Collections Scans can be initiated on demand regardless of the scan rate listed.

1. In ASM, from the **Collections** menu, select **Settings**.
2. To initiate a scan, click **Scan** associated with any Active Collection.

> ℹ️
>
> Collection scans run for a maximum of 72 hours.

![A Collection listing for a Collection in ASM, the Scan button is outlined.](https://storage.googleapis.com/gtidocresources/guides/asm/images/asm_collection_scan_rate_scan_collection_20240521.png)

## change-the-scan-rate-for-a-collection

> ℹ️
>
> Only users with Project Owner or Collection Admin permissions can change scan rates. For more information, see [ASM Roles and Permissions](../asm-roles-and-permissions.md).

1. In ASM, from the **Collections** menu, select **Settings**.
2. For any Active Collection, select the drop-down to select a different scan rate.

![](https://storage.googleapis.com/gtidocresources/guides/asm/images/asm_collection_scan_rate_frequency_20240521.png)
