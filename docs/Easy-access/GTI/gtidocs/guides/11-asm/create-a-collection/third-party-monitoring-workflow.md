# third-party-monitoring-workflow

Third Party Monitoring in Attack Surface Management (ASM) provides you with read-only access to Collections owned by other organizations. These read-only Collections are also referred to as Catalogues. Catalogues are useful for monitoring alerts and vulnerabilities that have been identified by vendors you interact with.

Here are some helpful hints to keep in mind when using the Third Party Monitoring Workflow:

* One Collection will be created for each Catalogue you add.
* You can only follow a specific Catalogue once. In the Third Party Monitoring Workflow, when you search for a Catalogue you already follow, you see a note that it's **Already added**.
* If you want to unfollow a Catalogue, you must archive your Collection that contains that Catalogue.
* There are a limited number of Third Party Collections that you can follow, depending on your subscription.

## create-a-collection-for-third-party-monitoring

1. In ASM, select **Settings** from the **Collections** dropdown.\
   ![The expanded Collections menu in Attack Surface Management.](https://storage.googleapis.com/gtidocresources/guides/asm/images/tp_workflow_collections_dropdown_20240514.png)
2. Click **+Create New Collection** .
3. Select **Third Party Monitoring**.
4. Click **I Accept** to accept the **Catalogue Acknowledgement**.
5. Search for Collections and click **Add Catalogue** for any you want to follow.
6. Click **Create Collection**

   > ℹ️
   >
   > If you add more than one Catalogue, the number of Collections created is equal to the number of Catalogues added.

![The Create a New Collection section showing the top five results when searching collections for ](https://storage.googleapis.com/gtidocresources/guides/asm/images/tp_workflow_new_collections_20240514.png)
