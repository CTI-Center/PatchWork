# inbound-integrations

Using inbound integrations, Attack Surface Management (ASM) leverages the API of various infrastructure vendors (DNS, cloud, and code repositories) to automatically pull or retrieve assets upon every scan refresh.

The following inbound integrations are supported by ASM.\
[DNS and CDN Integrations](#dns-and-cdn-integrations)\
[Cloud Integrations](#cloud-integrations)\
[Other Inbound Integrations](#other-inbound-integrations)
