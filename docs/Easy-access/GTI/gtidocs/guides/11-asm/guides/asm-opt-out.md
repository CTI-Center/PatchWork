# opt-out-of-attack-surface-management-scanning

The ASM Collection engines perform a variety of data-gathering tasks, all intended to find unknown assets and lightly gather enough information to determine the security posture for these assets. The gathered information is analyzed by our research team and proactively published to the owners of this information. No Collection task performed requires authorized access. It is intentionally designed to be light.

While you may have seen some alerts from your IDS or WAF, these are benign flags and are not indicative of malicious behavior. 

See [Scan Ranges](../create-a-collection/asm-scan-ranges.md) for source IP addresses – which can be allow-listed to ignore these alerts. If you would like to be excluded from active probes, let us know by contacting [Support (https://www.virustotal.com/gui/contact-us/technical-support)](https://www.virustotal.com/gui/contact-us/technical-support).
