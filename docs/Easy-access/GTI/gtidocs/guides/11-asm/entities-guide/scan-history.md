# scan-history

This feature lets you visualize changes to an Entity over time.

Some use cases include:

* Identifying Issues that have gone inactive.
* Identifying Technologies that have changed.

To access Scan History information, select an Entity and navigate to the **Scan History** tab.

![Scan History comparison of differences in an Entity on two different dates.](https://storage.googleapis.com/gtidocresources/guides/asm/images/entitities_scan_history_20240426.png)

Scans where the Entity was seen are listed as tiles. Up to the last 25 scans are provided. Scans where changes to the Entity were observed are represented in green. Grayed scans indicate that the Entity was unchanged for the given date.

The **Previous Scans** section defaults to the most recent scan where a change to the Entity was observed, provided that date differs from the **Current Scan**. You can select any previous scan to compare differences to the **Current Scan**. Select a specific date tile, or use the arrow buttons to toggle through the scans.
