# inferred-vulnerabilities

An inferred vulnerability, or CVE, is a vulnerability identified through a [passive check](issues-guide/how-issues-work.md) that recognizes a technology known to have a vulnerability associated with it. 

From the Attack Surface Management (ASM) [**Entities** page](https://asm.advantage.mandiant.com/entities), you can find CVEs in the following ways:

* For a list of the Entities that have at least one CVE, search for `vuln:cve`. ![Entities page showing vuln colon cve search results.](https://storage.googleapis.com/gtidocresources/guides/asm/images/entities_vuln_20240429.png)
* To locate URIs, the Entity type that is most likely to have CVEs, select the **Uri** filter.  ![Entities page showing a URI filter applied to a vuln colon cve search.](https://storage.googleapis.com/gtidocresources/guides/asm/images/entities_cve_uri_20240429.png)

For information on exporting a specific search, see [Exporting Search Results](exporting-search-results.md).

Select any Entity to bring up additional information. If there are any CVEs, they are shown on the **Inferred CVEs** tab.

![The Inferred CVEs tab for a specific Entity.](https://storage.googleapis.com/gtidocresources/guides/asm/images/entities_inferred_cves_20240429.png)
