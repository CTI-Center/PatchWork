# tld-list

[Typosquatting](https://en.wikipedia.org/wiki/Typosquatting) is related to misspellings in web addresses. Attack Surface Management (ASM) uses user-provided domains ([Seeds](understanding-attack-surface-management-seeds.md)) and common top-level domains (TLDs) to identify potential typosquat domains that are registered with malicious intent.

The [tlds-alpha-by-domain.txt](https://storage.googleapis.com/gtidocresources/guides/asm/tlds-alpha-by-domain.txt) file provides a list of TLDs that are used for discovery of typosquatted domains in ASM.
