# collection-search-modifiers

> 🚧 Special privileges required
>
> This feature is only available to users with the Enterprise or Enterprise Plus module.

Google Threat Intelligence allows you to perform advanced faceted searches over the historical set of collections. These searches can act on basically all the metadata that we generate for collections: name, threat actor, references, urls, malware role, tags, etc.

If you use top search bar or home search bar, Google Threat Intelligence searches by default over the historical collection of files, **in order to search over collections you need to add the facet condition entity:collection**. For example, let's ask for all those collections that contains more than 5 files and were first submitted after October 17th 2019:

[entity:collection files:5+ fs:2019-10-17+](https://www.virustotal.com/gui/search/entity%253Acollection%2520files%253A5%252B%2520fs%253A2019-10-17%252B/collections)

If you use collection search bar, Google Threat Intelligence searches over the historical set of collections, as the image below. For example, let's ask for all those collections that contains more than 5 files and were first submitted after October 17th 2019:

[files:5+ fs:2019-10-17+](https://www.virustotal.com/gui/search/entity%253Acollection%2520files%253A5%252B%2520fs%253A2019-10-17%252B/collections)

Note that you're able to build complex searches combining **AND, OR and NOT** conditions. For example:

[(entity:collection AND files:5+ AND fs:2019-10-17+) AND (threat\_actor:apt29 OR threat\_actor:"mummy spider")](https://www.virustotal.com/gui/search/\(entity%253Acollection%2520AND%2520files%253A5%252B%2520AND%2520fs%253A2019-10-17%252B\)%2520AND%2520\(threat_actor%253Aapt29%2520OR%2520threat_actor%3A%22mummy_spider%22\)/collections)

You can directly type these modifiers on the collection search box:

<img src="https://storage.googleapis.com/gtidocresources/guides/ioc-investigation/intelligence/images/collection_search_modifiers_bar_20240726.png" alt="Collection Search Modifiers search box" style={{ display: 'block', margin: '0 auto' }} />

The following table describes all the search modifiers (facets) that can be used, you can combine any number of them:

|                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **available\_mitigation**                | Search for vulnerabilities whose mitigation is the text provided. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability available\_mitigation:Patch](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20available_mitigation%3APatch)                                                                                                                                                                                                            |
| **collection\_type**                     | Search for the type of the collection.<br />Example:[entity:collection collection\_type:vulnerability](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability)                                                                                                                                                                                                                                                                                                                                      |
| **comment\_author**                      | Search for collections that have been commented by the user with the username provided.<br />Example: [entity:collection comment\_author:68h7EGyNm](https://www.virustotal.com/gui/search/entity%253Acollection%2520comment_author%253A68h7EGyNm)                                                                                                                                                                                                                                                                                        |
| **creation\_date**                       | Filter collections based on its creation date. Accepts less than and greater than syntax.<br />Examples: [entity:collection creation\_date:2020-02-10+](https://www.virustotal.com/gui/search/entity%253Acollection%2520creation_date%253A2020-02-10%252B), [entity:collection creation\_date:2020-02-10-,](https://www.virustotal.com/gui/search/entity%253Acollection%2520creation_date%253A2020-02-10-) [entity:collection creation\_date:3d-](https://www.virustotal.com/gui/search/entity%253Acollection%2520creation_date%253A3d-) |
| **cvss\_3x\_base\_score**                | Filter vulnerabilities based on its CVSS 3.X base score. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability cvss\_3x\_base\_score:6+](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20cvss_3x_base_score%3A6%2B)                                                                                                                                                                                                                           |
| **cvss\_3x\_temporal\_score**            | Filter vulnerabilities based on its CVSS 3.X temporal score. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability cvss\_3x\_temporal\_score:7-](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20cvss_3x_temporal_score%3A7-)                                                                                                                                                                                                                 |
| **cvss\_2x\_base\_score**                | Filter vulnerabilities based on its CVSS 2.X base score. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability cvss\_2x\_base\_score:7+](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20cvss_2x_base_score%3A7%2B)                                                                                                                                                                                                                           |
| **cvss\_2x\_temporal\_score**            | Filter vulnerabilities based on its CVSS 2.X temporal score. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability cvss\_2x\_temporal\_score:8-](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20cvss_2x_temporal_score%3A8-)                                                                                                                                                                                                                 |
| **description**                          | Search for collections that have a description containing the word or phrase provided. <br />Example: [entity:collection description:IOCs](https://www.virustotal.com/gui/search/entity%253Acollection%2520description%253AIOCs)                                                                                                                                                                                                                                                                                                         |
| **domains**                              | Filter collections based on the number of domains included on the collection. Accepts less than and greater than syntax.<br />Examples: [entity:collection domains:5+](https://www.virustotal.com/gui/search/entity%253Acollection%2520domains%253A5%252B)                                                                                                                                                                                                                                                                               |
| **exploitation\_consequence**            | Filter vulnerabilities whose exploitation consequence matches the text provided. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability exploitation\_consequence:"Denial-of-Service (DoS)"](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20exploitation_consequence%3A%22Denial-of-Service%20%28DoS%29%22)                                                                                                                                   |
| **exploitation\_state**                  | Filter vulnerabilities whose exploitation state matched the text provided. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability exploitation\_state:Confirmed](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20exploitation_state%3AConfirmed)                                                                                                                                                                                               |
| **exploitation\_vector**                 | Filter vulnerabilities whose exploitation vector matched the text provided. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability exploitation\_vector:Web](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20exploitation_vector%3AWeb)                                                                                                                                                                                                        |
| **files**                                | Filter collections based on the number of files included on the collection. Accepts less than and greater than syntax.<br />Examples: [entity:collection files:5+](https://www.virustotal.com/gui/search/entity%253Acollection%2520files%253A5%252B)                                                                                                                                                                                                                                                                                     |
| **fs**<br />**first\_seen**              | Filter collections based on the first seen date in VirusTotal. Note that less than and greater than syntax is allowed.<br />Examples: [entity:collection fs:2019-10-10+](https://www.virustotal.com/gui/search/entity%253Acollection%2520fs%253A2019-10-10%252B), [entity:collection fs:2019-10-10-](https://www.virustotal.com/gui/search/entity%253Acollection%2520fs%253A2019-10-10-)                                                                                                                                                 |
| **have**<br />**has**                    | Search the collections which report contains information from the selected field it accepts any of the modifiers described in this arcticle.<br />Example: [entity:collection have:comment](https://www.virustotal.com/gui/search/entity%253Acollection%2520have%253Acomment)                                                                                                                                                                                                                                                            |
| **ips**<br />**ip\_addresses**           | Filter collections based on the number of ip addresses included on the collection. Accepts less than and greater than syntax.<br />Examples: [entity:collection ips:5+](https://www.virustotal.com/gui/search/entity%253Acollection%2520ips%253A5%252B)                                                                                                                                                                                                                                                                                  |
| **last\_modification\_date**<br />**lm** | Filter collections based on the last modification date. Note that less than and greater than syntax is allowed.<br />Examples: [entity:collection lm:2019-10-10+](https://www.virustotal.com/gui/search/entity%253Acollection%2520lm%253A2019-10-10%252B) , [entity:collection lm:2019-10-10-](https://www.virustotal.com/gui/search/entity%253Acollection%2520lm%253A2019-10-10-)                                                                                                                                                       |
| **ls**<br />**last\_seen**               | Filter collections based on the last seen date in VirusTotal. Note that less than and greater than syntax is allowed.<br />Examples: [entity:collection ls:2019-10-10-](https://www.virustotal.com/gui/search/entity%253Acollection%2520ls%253A2019-10-10-), [entity:collection ls:2019-10-10+](https://www.virustotal.com/gui/search/entity%253Acollection%2520ls%253A2019-10-10%252B)                                                                                                                                                  |
| **merged\_actor**                        | Filter threat actors that are associated with the provided group. Only available for Threat Actors.<br />Example:[entity:collection collection\_type:threat-actor merged\_actor:UNC1285](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Athreat-actor%20merged_actor%3AUNC1285)                                                                                                                                                                                                                            |
| **name**                                 | Search for collections whose name containing the word or phrase provided. <br />Example: [entity:collection name:malware](https://www.virustotal.com/gui/search/entity%253Acollection%2520name%253Amalware)                                                                                                                                                                                                                                                                                                                              |
| **owner**                                | Search for collections that have been created by an specific owner. <br />Example: [entity:collection owner:CarlosCabal](https://www.virustotal.com/gui/search/entity%253Acollection%2520owner%25253ACarlosCabal)                                                                                                                                                                                                                                                                                                                        |
| **publisher**                            | Search for reports whose publisher matches the text provided.<br />Example:[entity:collection collection\_type:report publisher:Google TAG](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Areport%20publisher%3AGoogle%20TAG)                                                                                                                                                                                                                                                                             |
| **publisher\_priority**                  | Filter reports according to the priority score of the publisher.<br />Example:[entity:collection collection\_type:report publisher\_priority:50-](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Areport%20publisher_priority%3A50-)                                                                                                                                                                                                                                                                       |
| **publisher\_relevance**                 | Filter reports based on the relevance score of the publisher. Only available for Reports<br />Example:[entity:collection collection\_type:report publisher\_relevance:70-](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Areport%20publisher_relevance%3A70-)                                                                                                                                                                                                                                             |
| **publisher\_reliability**               | Filter reports based on the reliability score of the publisher.<br />Example:[entity:collection collection\_type:report publisher\_reliability:80-](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Areport%20publisher_reliability%3A80-)                                                                                                                                                                                                                                                                  |
| **references**                           | Filter collections based on the number of references included on the collection. Accepts less than and greater than syntax.<br />Examples: [entity:collection references:5+](https://www.virustotal.com/gui/search/entity%253Acollection%2520references%253A5%252B)                                                                                                                                                                                                                                                                      |
| **report\_type**                         | Search for reports whose type matches the text provided. Only available for Google TI Enterprise license or higher.<br />Example:[entity:collection collection\_type:report report\_type:"OSINT article"](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Areport%20report_type%3A%22OSINT%20article%22)                                                                                                                                                                                                    |
| **risk\_rating**                         | Filter vulnerabilities whose risk rating matches the text provided. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability risk\_rating:high](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20risk_rating%3Ahigh)                                                                                                                                                                                                                              |
| **shared\_with\_me**                     | Filter collections that have been shared with me.<br />Example:[entity:collection shared\_with\_me:true](https://www.virustotal.com/gui/search/entity%3Acollection%20shared_with_me%3Atrue)                                                                                                                                                                                                                                                                                                                                              |
| **sigma\_rules**                         | Filter collections based on the number of sigma rules included on the collection. Accepts less than and greater than syntax.<br />Examples: [entity:collection sigma\_rules:5+](https://www.virustotal.com/gui/search/entity%253Acollection%2520sigma_rules%253A5%252B)                                                                                                                                                                                                                                                                  |
| **software\_toolkit**                    | Filter collections that are associated with the software toolkit provided. Only available for Google TI Enterprise license or higher.<br />Example:[entity:collection software\_toolkit:DCSYNCER](https://www.virustotal.com/gui/search/entity%3Acollection%20software_toolkit%3ADCSYNCER)                                                                                                                                                                                                                                               |
| **source\_region**                       | Filter collections which have that related source regions. Accept the region in ISO code 2 format <br />Example: [entity:collection source\_region:"US"](https://www.virustotal.com/gui/search/entity%253Acollection%2520source_region%253AUS)                                                                                                                                                                                                                                                                                           |
| **suspected\_threat\_actor**             | Filter threat actors that are suspected to be associated, not yet confirmed, with the provided group. Only available for Threat Actors.<br />Example:[entity:collection collection\_type:threat-actor suspected\_threat\_actor:UNC1285](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Athreat-actor%20suspected_threat_actor%3AUNC1285)                                                                                                                                                                   |
| **tag**                                  | Filter collections according to their tags.<br />Example: [entity:collection tag:attachment](https://www.virustotal.com/gui/search/entity%253Acollection%2520tag%253Aattachment)                                                                                                                                                                                                                                                                                                                                                         |
| **targeted\_industry**                   | Filter collections which have that related targeted industry. Accept the region in ISO code 2 format <br />Example: [entity:collection targeted\_industry:"banking"](https://www.virustotal.com/gui/search/entity%253Acollection%2520targeted_industry%253Abanking)                                                                                                                                                                                                                                                                      |
| **targeted\_industry\_group**            | Filter collections whose targeted\_industry belong to the targeted\_industry\_group provided.<br />Example:[entity:collection targeted\_industry\_group:"aerospace & defense"](https://www.virustotal.com/gui/search/entity%3Acollection%20targeted_industry_group%3A%22aerospace%20%26%20defense%22)                                                                                                                                                                                                                                    |
| **targeted\_region**                     | Filter collections which have that related targeted regions. Accept the region in ISO code 2 format <br />Example: [entity:collection targeted\_region:"US"](https://www.virustotal.com/gui/search/entity%253Acollection%2520targeted_region%253AUS)                                                                                                                                                                                                                                                                                     |
| **threat\_actor**                        | Filter collections which have that related threat actor. <br />Example: [entity:collection threat\_actor:"Lazarus Group"](https://www.virustotal.com/gui/search/entity%253Acollection%2520threat_actor%253A%2522Lazarus%2520Group%2522)                                                                                                                                                                                                                                                                                                  |
| **threat\_actors**                       | Filter collections based on the number of threat actors included on the collection. Accepts less than and greater than syntax.<br />Examples: [entity:collection threat\_actors:5+](https://www.virustotal.com/gui/search/entity%253Acollection%2520threat_actors%253A5%252B)                                                                                                                                                                                                                                                            |
| **threat\_category**                     | Filter collections which have that related threat category associated to the files in the collection. <br />Example: [entity:collection threat\_category:"banker"](https://www.virustotal.com/gui/search/entity%253Acollection%2520threat_category%253Abanker)                                                                                                                                                                                                                                                                           |
| **threat\_scape**                        | Filter reports whose topic is the provided text. Only available for Reports.  Only available for Google TI Enterprise license or higher.<br />Example:[entity:collection collection\_type:report threat\_scape:"Cyber crime"](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Areport%20threat_scape%3A%22Cyber%20crime%22)                                                                                                                                                                                 |
| **urls**                                 | Filter collections based on the number of urls included on the collection. Accepts less than and greater than syntax.<br />Examples: [entity:collection urls:5+](https://www.virustotal.com/gui/search/entity%253Acollection%2520urls%253A5%252B)                                                                                                                                                                                                                                                                                        |
| **vulnerable\_cpe**                      | Filter vulnerabilities based on the standarized product naming scheme provided. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability vulnerable\_cpe:"2.3:a:siemens:nucleus\_readystart:2012.12:*:*:*:*:*:*:\*"](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20vulnerable_cpe%3A%222.3%3Aa%3Asiemens%3Anucleus_readystart%3A2012.12%3A%2A%3A%2A%3A%2A%3A%2A%3A%2A%3A%2A%3A%2A%22)                                                          |
| **vulnerable\_vendor**                   | Filter vulnerabilities using the vendor with know security flags provided. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability vulnerable\_vendor:Adobe](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20vulnerable_vendor%3AAdobe)                                                                                                                                                                                                         |
| **vulnerable\_product**                  | Filter vulnerabilities using the product with know security flags provided. Only available for Vulnerabilities.<br />Example:[entity:collection collection\_type:vulnerability vulnerable\_product:"Adobe Reader"](https://www.virustotal.com/gui/search/entity%3Acollection%20collection_type%3Avulnerability%20vulnerable_product%3A%22Adobe%20Reader%22)                                                                                                                                                                              |
| **yara\_rulesets**                       | Filter collections based on the number of yara rulesets included on the collection. Accepts less than and greater than syntax.<br />Examples: [entity:collection yara\_rulesets:5+](https://www.virustotal.com/gui/search/entity%253Acollection%2520yara_rulesets%253A5%252B)                                                                                                                                                                                                                                                            |
| **malware\_role**                        | Filter collections which have that malware role. <br />Example: [entity:collection malware\_role:backdoor-botnet](https://www.virustotal.com/gui/search/entity%253Acollection%2520malware_role%253Abackdoor-botnet)                                                                                                                                                                                                                                                                                                                      |
| **motivation**                           | Filter collections which have that motivation. <br />Example: [entity:collection motivation:ideological](https://www.virustotal.com/gui/search/entity%253Acollection%2520motivation%253Aideological)                                                                                                                                                                                                                                                                                                                                     |
| **operating\_system**                    | Filter collections which have operating system related to their files. <br />Example: [entity:collection operating\_system:linux](https://www.virustotal.com/gui/search/entity%253Acollection%2520operating_system%253Alinux)                                                                                                                                                                                                                                                                                                            |
| **detection**                            | Search for collections whose detections associated to the files containing the word or phrase provided. <br />Example: [entity:collection detection:Trojan](https://www.virustotal.com/gui/search/entity%253Acollection%2520detection%253Atrojan)                                                                                                                                                                                                                                                                                        |
| **capability**                           | Search for collections whose capabilities associated to the files containing the word or phrase provided. <br />Example: [entity:collection detection:"capture credentials"](https://www.virustotal.com/gui/search/entity%253Acollection%2520capability%253A%2522capture%2520credentials%2522)                                                                                                                                                                                                                                           |
| **origin**                               | Search for collections whose report author containing the word or phrase provided. <br />Example: [entity:collection origin:"google threat intelligence"](https://www.virustotal.com/gui/search/entity%253Acollection%2520origin%253A%2522google%2520threat%2520intelligence%2522)                                                                                                                                                                                                                                                       |
