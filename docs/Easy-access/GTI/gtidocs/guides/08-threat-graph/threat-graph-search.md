# search-and-start-new-investigation

# search

***

You can search for entities and/or graphs using the search bar at the top of the page.

![Graph search form](https://storage.googleapis.com/gtidocresources/guides/threat-graph/images/graphsearch_form_20240405.png)

Multiple entity identifiers can be searched at the same time as far as you press the *space* key between each of them. You can make a search easily using the filter.

![Graph search settings](https://storage.googleapis.com/gtidocresources/guides/threat-graph/images/graphsearch_settings_20240405.png)

Once you perform the search, you will be redirect to the search page where you will see the list of graphs that matches the query:

![Graph search results](https://storage.googleapis.com/gtidocresources/guides/threat-graph/images/graphsearch_results_20240405.png)

If you search for some entities, you can open a graph with them clicking on the button "Start new graph investigation".

* If there is only one entity, the graph will be opened with it and will this entity will be full expanded.
* If there are more than one entity, the playbooks modal will be prompted to let you configure the new investigation.
