# what-kind-of-files-will-google-threat-intelligence-scan?

Google Threat Intelligence will scan, and detect, if appropriate, any type of binary content, be it a Windows executable, Android APKs, PDFs, images, javascript code, etc. Most of the antivirus companies involved in Google Threat Intelligence will have solutions for multiple platform, hence they usually produce detection signatures for any kind of malicious content.
