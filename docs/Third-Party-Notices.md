## Before-publication

Record the applicable licence/permission and any required attribution for each
included source and asset. Review source-derived wording in report descriptions
as well as the full reference copies. A publicly readable page, attribution,
TLP:CLEAR marking or successful link check is not itself a copyright licence.

If permission cannot be established, decide on a links-only reference edition
or obtain permission before publication. Do not silently delete references:
the framework depends on their section links, so an edition that removes them
must update those citations and revalidate the exported package.

No tool in this repository approves third-party rights. See the
[publication checklist](Publication-Checklist.md) for the release gates.
